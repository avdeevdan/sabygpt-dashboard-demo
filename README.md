# SabyGPT — демо конструктора дашборда

Кликабельная демка окна SabyGPT в режиме редактирования дашборда. Макет: Figma, файл «Генерация дашбордов», узел 19:10498.

## Запуск локально
Открыть `index.html` в браузере (сборка не нужна). Либо `python -m http.server` в этой папке.

## Что умеет
- кнопка SabyGPT в верхней панели открывает окно;
- пресеты + ручной ввод промта, загрузка промта из файла, смена модели;
- «генерация» (имитация) → зелёная галочка → «Заменить текущий» / «Добавить в текущий дашборд».

## Картинки из Figma
Четыре картинки центральной зоны (узлы 19:10505, 19:10507, 19:10510, 19:10512) положить в `assets/` как `w1.png`, `w2.png`, `w3.png`, `w4.png` (экспорт PNG @2x) — они встанут в сетку сами.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
